# Проектирование тестов по критерию C2

Критерий C2 интерпретируется как покрытие независимых путей управляющего графа. Для циклов проверены случаи с нулём, одной и несколькими итерациями: перечислить буквально все пути циклической программы невозможно, так как число итераций не ограничено.

| Метод | Существенные пути | Тесты |
|---|---|---|
| `Playlist` | допустимая и недопустимая вместимость | `CreatesEmptyPlaylistWithSpecifiedCapacity`, `RejectsNonPositiveCapacity` |
| копирование и присваивание | копирование элементов; присваивание другому объекту; самоприсваивание | `CopyConstructorCreatesIndependentCopy`, `AssignmentCopiesDataAndHandlesSelfAssignment` |
| `operator[]` | допустимый индекс; индекс меньше нуля; индекс не меньше `Count` | `ReadsAndReplacesExistingTrack`, `RejectsIndexesOutsideOccupiedRange` |
| `operator==` | разное число треков; первое несовпадение; полное совпадение; пустые списки | `ComparesCountOrderAndTrackIdentity` |
| `Contains` / `Add` | пустой список; найденный и отсутствующий элемент; свободное место; дубликат; переполнение | группа `PlaylistAddTests` |
| `Merge` | пустой источник; только дубликаты; смесь дубликатов и новых треков; недостаток места | группа `PlaylistMergeTests` |
| `RemoveTracksOf` | совпадений нет; удаление нескольких элементов; сохранение порядка оставшихся | группа `PlaylistRemoveTests` |
| `TotalDuration` | пустой плейлист; несколько треков | `ReturnsZeroForEmptyAndSumForFilledPlaylist` |
| `FindByArtist` | совпадение в начале; совпадение после нескольких итераций; отсутствие совпадения | группа `PlaylistFindTests` |
| `ToString` | пустой плейлист; несколько строк; дополнение секунд нулём | `FormatsEachTrackAndPadsSeconds` |

Дополнительно тесты проверяют, что исключительные пути не изменяют состояние плейлиста, а копии владеют независимыми массивами.
