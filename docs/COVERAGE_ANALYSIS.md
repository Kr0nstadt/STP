# Тестовые случаи и анализ покрытия

Для циклов критерий C2 рассматривается как покрытие независимых путей: ноль, одна и несколько итераций, а также истинная и ложная ветви условий внутри цикла. Полный перебор буквально всех путей невозможен для циклов с произвольным числом итераций.

## Функции из приложения

| Функция | Входные данные | Ожидаемый результат | Покрываемый путь |
|---|---|---|---|
| `applyDiscount` | `-1, false` | `-1` | ошибка: первое условие истинно |
| | `4999, false` | `4999` | обе границы скидки ложны |
| | `5000, false` | `4750` | средний диапазон, обычный клиент |
| | `7500, true` | `6750` | средний диапазон, премиум-клиент |
| | `10000, false` | `8500` | верхний диапазон, обычный клиент |
| | `12000, true` | `9600` | верхний диапазон, премиум-клиент |
| `calcShipping` | `-0.01` | `-1` | ошибочный ввод |
| | `4999.99` | `300` | платная доставка |
| | `5000`, `10000` | `0` | бесплатная доставка и граничное значение |
| `finalPrice` | по одному отрицательному аргументу | `-1` | три пути короткого замыкания `||` |
| | `100, 200, 50` | `0` | отрицательный промежуточный результат |
| | `1000.125, 200, 100` | `900.13` | обычный результат и округление |
| `countExpensiveItems` | `{}`, `100` | `0` | ноль итераций |
| | `{10, 20}`, `50` | `0` | ложная ветвь внутреннего условия |
| | `{99, 100, 101, 250}`, `100` | `2` | несколько итераций, обе ветви условия |

Тесты `calcShipping(4999.99)` и `calcShipping(5000)` воспроизводят ошибку исходного листинга: условие `total <= 5000` назначало бесплатную доставку дешёвому заказу. После замены на `total >= 5000` оба теста проходят и поведение соответствует текстовой спецификации.

## Итог по критериям

- **C0:** каждый оператор функций выполняется хотя бы одним тестом.
- **C1:** для каждого решения проверены истинная и ложная ветви, включая условия циклов.
- **C2:** пройдены все независимые ациклические пути; для циклов проверены 0, 1 и несколько итераций.

Workflow GitHub Actions собирает проект с флагами покрытия GCC, запускает тесты и сохраняет HTML-отчёт `lab1-coverage-report` как артефакт запуска.
