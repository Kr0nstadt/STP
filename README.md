# Лабораторная работа №2 — Playlist

Реализация класса `Playlist` для хранения музыкальных треков ограниченной вместимости и набор модульных тестов на Google Test.

## Реализованные операции

- создание, копирование и присваивание плейлистов;
- чтение и изменение трека через `operator[]`;
- сравнение плейлистов;
- добавление трека с проверкой переполнения и дубликатов;
- объединение плейлистов без дублирования;
- удаление треков, содержащихся в другом плейлисте;
- вычисление общей длительности;
- поиск первого трека исполнителя;
- строковое представление в формате `Исполнитель - Название (мм:сс)`.

## Сборка и тестирование

Требуются CMake 3.15+, компилятор с поддержкой C++17 и подключение к Интернету при первой конфигурации для загрузки Google Test.

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build
ctest --test-dir build --output-on-failure
```

Описание тестовых путей по критерию C2 находится в [docs/C2_TEST_DESIGN.md](docs/C2_TEST_DESIGN.md).
