# Лабораторная работа №10 — параллельный grep

`pgrep` ищет фиксированную подстроку в текстовых файлах. Требуются C++17 и CMake 3.16 или новее.

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
./build/pgrep -rin -j 4 error ./logs
```

Запуск: `pgrep [OPTIONS] PATTERN [PATH...]`. Без путей используется текущий каталог. Каталоги обходятся с `-r`, символические ссылки пропускаются.

| Опция | Действие |
| --- | --- |
| `-r` | Рекурсивный обход |
| `-i` | Поиск без учёта регистра ASCII |
| `-v` | Строки без совпадения |
| `-n` | Номер строки |
| `-H` / `-h` | Всегда / никогда показывать путь |
| `-c` / `-l` | Число совпавших строк / имена файлов с совпадениями |
| `-w` / `-x` | Целое слово / целая строка |
| `-j N` | Число рабочих потоков, `-j 1` включает последовательный режим |
| `-q` | Тихий режим |
| `--` | Конец опций, например `pgrep -- -foo a.txt` |

Главный поток собирает пути. Каждый рабочий поток забирает файл из общей очереди и читает его целиком, а вывод защищён мьютексом. Порядок строк от разных файлов может меняться. Сводка печатается в stderr после завершения поиска. Код возврата 0 означает совпадение, 1 — отсутствие совпадений, 2 — ошибку поиска или аргументов.
