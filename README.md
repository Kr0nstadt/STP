# Современные технологии программирования

Репозиторий с лабораторными работами по дисциплине «Современные технологии программирования».

Каждая лабораторная работа находится в отдельной ветке:

- `lab1` — структурное тестирование и критерии покрытия C0, C1, C2;
- `lab2` — разработка и модульное тестирование класса `Playlist`;
- `lab3` — абстракция и шаблоны в приложении Task Manager.

Инструкции по сборке и запуску тестов приведены в README соответствующей ветки.
