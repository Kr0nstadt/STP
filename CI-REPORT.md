# Лабораторная работа №6 — GitHub Actions

В `.github/workflows/ci.yml` одна матрица для Ubuntu, macOS и Windows. На каждом раннере CMake собирает один и тот же проект C++17 и CTest запускает один и тот же набор тестов. Конфигурация Release задаётся и при сборке, и при тестировании, чтобы на Windows выбиралась правильная конфигурация.

## Проверка fail-fast

В ручном запуске можно включить дополнительный тест `ci_intentional_failure` для Ubuntu. Обычные push и pull request запускают только основной набор.

| Запуск | Ubuntu | macOS | Windows |
| --- | --- | --- | --- |
| [fail-fast=false](https://github.com/Kr0nstadt/STP/actions/runs/43880890474) | Тест завершился ошибкой | Успех | Успех |
| [fail-fast=true](https://github.com/Kr0nstadt/STP/actions/runs/43881178031) | Тест завершился ошибкой | Отменено | Отменено |
| [Обычный запуск](https://github.com/Kr0nstadt/STP/actions/runs/43881359319) | Успех | Успех | Успех |

При `false` можно увидеть результат всех платформ за один запуск. При `true` ошибка одного задания останавливает остальные задания, которые ещё выполняются или ждут очереди.

## Кэш

В кэше находятся распакованные исходники yaml-cpp и GoogleTest. Ключ учитывает ОС, архитектуру, CMake и workflow. В таблице указано время выполнения задания от старта до завершения по журналу Actions, без ожидания раннера.

| Запуск | Ubuntu, с | macOS, с | Windows, с | Результат по журналу |
| --- | ---: | ---: | ---: | --- |
| [Первый](https://github.com/Kr0nstadt/STP/actions/runs/43880070375/attempts/1) | 38 | 55 | 84 | Промах на всех ОС |
| [Повтор того же коммита](https://github.com/Kr0nstadt/STP/actions/runs/43880070375/attempts/2) | 29 | 36 | 72 | Попадание на всех ОС |
| [После изменения src/main.cpp](https://github.com/Kr0nstadt/STP/actions/runs/43881359319) | 45 | 56 | 68 | Попадание на всех ОС |

Изменение исходника приложения сохранило ключ. Зависимости не скачивались заново, но компиляция выполнялась на каждом запуске. Общее время зависит также от скорости раннера, сборки и загрузки артефактов. Поэтому в третьем запуске Ubuntu и macOS отработали дольше, чем в первом, хотя кэш восстановился.

## Артефакты и платформы

Каждое задание сохраняет XML-отчёт CTest и журнал `LastTest.log`, если они созданы. В скачанном архиве Ubuntu были оба файла. XML содержал 13 тестов и 0 ошибок. Кэш ускоряет другие запуски, а артефакт хранит результат конкретного запуска и доступен для скачивания.

Проверка на трёх системах помогает находить отличия в компиляторах, системных библиотеках, путях и конфигурациях сборки. Успешная сборка на одном раннере проверяет только его окружение.
